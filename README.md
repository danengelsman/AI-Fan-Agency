# AI Fan Agency

**Done-For-You AI Influencer Studio — Transparent. Profitable. Disclosed.**

Build, manage, and monetize AI influencer personas across Fanvue, Instagram, TikTok, X, and Reddit. Every fan interaction carries a visible AI label — better retention, zero platform bans, full compliance.

## Stack

- React 19 + TypeScript + Vite 6
- Tailwind CSS 4
- Framer Motion (animations)
- Lucide Icons

## Quick Start

```bash
npm install
npm run dev      # Dev server on :3001
npm run build    # Production build to dist/
npm run preview  # Preview the production build
```
